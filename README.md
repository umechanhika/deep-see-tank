# deep-see-tank — 深海水槽放置ゲーム

暗い深海水槽を眺めるだけで生態系が育っていく、ブラウザで動く箱庭系の放置ゲーム。
同じゲームを 2 つの 3D 技術で作っており、どちらもブラウザで遊べる。

| 版 | ディレクトリ | 公開先（GitHub Pages） |
|---|---|---|
| three.js 版 | [`three/`](three/) | サイトのルート `/` |
| Flutter Scene 版 | [`flutter/`](flutter/) | サイトの `/flutter/` |

開発のしかたは各ディレクトリの README を参照。

## 遊び方

- **ドラッグ**: 視点を回す。操作しなければ自動でゆっくり回転する。
- **ホイール / ピンチ**: 水槽に寄る・離れる。
- **クリック**: その地点に餌をまく。魚が集まり、珊瑚が少し成長する。
- **ホバー**: 生き物にカーソルを合わせると名前とレベルを表示する。

時間経過（累計プレイ時間）でフェーズが進み、生き物が増えていく。
ページを閉じている間の経過も、最大 24 時間まで反映される。

## フェーズ進行

| フェーズ | 到達時間 | 内容 |
|---|---|---|
| 1 | 開始直後 | プランクトン |
| 2 | 5分後 | 発光クラゲ出現（最大5体） |
| 3 | 15分後 | 魚の群れ（Boid・最大30匹） |
| 4 | 30分後 | 深海魚（チョウチンアンコウ） |
| 5 | 60分後 | 完成形 |

## デプロイ

`.github/workflows/deploy.yml` が両方の版をビルドし、1 つのサイトにまとめて GitHub Pages へ公開する。

- `main` へのマージ: 本番（`gh-pages` ブランチのルート）
- プルリクエスト: プレビュー（`pr-preview/pr-<番号>/`）。プルリクエストにプレビューの URL がコメントされる。
